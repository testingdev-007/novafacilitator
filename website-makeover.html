# Website Makeover — Combined Reference This file collects the intended bugs, design flaws, and checklist items for both dashboard challenges in one place. ## Section 1 — `bank-dashboard-01.html` ### Bugs - [ ] The balance number is invisible on the hero card. - [ ] The balance card layout is broken because the closing structure is missing. - [ ] Costa Coffee is shown as money coming in instead of money out. - [ ] The Withdraw button does nothing. - [ ] Withdrawing increases the balance instead of reducing it. - [ ] The interest calculator gives the wrong answer. - [ ] The balance display never updates on screen because the script targets the wrong element. - [ ] Invalid withdrawals are not blocked. - [ ] The interest calculator can show `NaN`. - [ ] The Withdraw button uses an arrow cursor instead of a pointer. ### Design flaws - [ ] Balance text is hard to read. - [ ] Header action buttons are too small. - [ ] Icon buttons lack accessible names. - [ ] Inputs and buttons do not show a clear focus state. - [ ] Transaction dates are too small and low contrast. - [ ] The layout is weak on narrow screens. - [ ] Status messaging relies too much on colour. - [ ] The interest calculator labels are not fully connected. - [ ] The Withdraw field uses the wrong input type for mobile. - [ ] Buttons need better hover and pressed states. ## Section 2 — `bank-dashboard-02.html` ### Bugs - [ ] The mortgage balance, payment, or summary values do not update consistently. - [ ] Overpayment validation allows invalid or impossible values. - [ ] The overpayment calculation can produce the wrong balance or repayment outcome. - [ ] The schedule or repayment figures do not reflect the current mortgage state after a change. - [ ] The interest/projection calculator can show incorrect or unhelpful output. - [ ] Console errors may prevent some interactions from working correctly. ### Design flaws - [ ] The page needs stronger accessibility for keyboard and screen reader users. - [ ] The layout should adapt more cleanly on smaller screens. - [ ] Buttons, inputs, and cards need more polished spacing and hierarchy. - [ ] Important messages should be clearer and not depend on colour alone. - [ ] The page should feel more like a premium mortgage dashboard. - [ ] Hover, focus, and active states should be more obvious. - [ ] Form controls should be easier to scan and use. ## Section 3 — Suggested checklist format Use this pattern in the final page so learners can tick items off as they go: ### Bugs - [ ] Bug name or description here - [ ] Another bug here ### Design improvements - [ ] Improvement name or description here - [ ] Another improvement here ## Section 4 — Notes - Keep the headings clear and separate for each dashboard. - Keep the checklist items clickable so learners can mark progress. - Keep the language student-friendly and specific. - If you want, you can add brief hints under each checklist item.
